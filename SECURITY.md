# Security Policy

## Supported Versions

Only the latest `0.x` minor is supported during the pre-1.0 phase.

## Reporting a Vulnerability

**Do not open a public GitHub issue for security reports.**

Email: `mail@florian-chiorean.de` — or DM `unfloned` on our [Discord](https://discord.gg/pbXw4acstw).

Expect an acknowledgement within 72 hours. Once the issue is confirmed and a
fix is ready, a coordinated disclosure + patched release will follow.
